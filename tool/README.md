# TaskReader — 中文任务提取工具

从一句中文自然语言中提取出其中的**任务/计划**（动作、对象、时间、地点），
并输出结构化 JSON。示例：

```
输入: 我下周三要交论文
输出: [{"task":"交论文","action":"交","object":"论文","time_start":"2026-08-05","time_end":"2026-08-05","time":"2026-08-05","time_text":"下周三","place":"","notes":"","raw":"我下周三要交论文","confidence":0.935,"source":"rule"}]
```

还支持**结构化列表 + 头部时间上下文**：

```
输入: 今天任务：1.看完夏商周的网课，记笔记 2.对照大纲补充笔记 3.刷小程序上的真题
输出: 3 条任务（每条 time 都取头部"今天"作为默认时间；第 1 条 notes 记录"记笔记"）
```

## 架构：混合三层流水线

```
输入句子
  ├─ 预处理(全角→半角、标点统一、简繁可选)          normalize.py
  ├─ 分句(按标点/然后/顺便等切分多任务)               segment.py
  │    └─ 结构化列表(1. 2. 3. / 1、2、)：一个序号=一条任务，项内逗号不拆分
  │    └─ 头部时间上下文(今天任务：/ 周五计划：)：剥离标题，其时间作为整批默认时间
  └─ 每个子句:
       ├─ 规则抽取: 时间/地点/动作 三路并行          time_parser.py place_parser.py action_parser.py
       └─ LLM 兜底: 规则找不到动作时才调用本地模型     llm.py
  └─ 融合 + 置信度评分                                 engine.py
```

- **规则通道**：确定性、离线、零延迟。负责时间归一化（`下周三`→`2026-08-05`，
  以参考日期为基准换算相对时间）、地点词典匹配、动词+宾语抽取（含"把"字句）。
- **LLM 通道**：本地 **Ollama + qwen3:8b**，数据不出本机。
  仅当规则层未能识别动作时才调用（节省算力，规则覆盖的句子秒出）。
  两者按字段互补融合（`hybrid`）。
- **结构化列表**：`1.xxx 2.yyy` 或 `1、xxx2、yyy` 自动识别；列表项内出现多个动词时
  合并为单任务（首个动作为主任务，其余进 `notes`），避免把一项拆成多条。

## 快速开始

```bash
# 依赖
pip install -r requirements.txt

# 规则模式（不依赖 LLM，秒出）
python -m task_reader.cli "我下周三要交论文" --no-llm

# 混合模式（默认，需要 Ollama + qwen3:8b）
python -m task_reader.cli "我们周五晚上六点在学校门口集合，然后一起去图书馆把书还了，顺便去食堂吃饭"

# 指定参考日期（默认今天）
python -m task_reader.cli "两周后交作业" --ref 2026-08-02

# 从 stdin 批量读取，每行一句
type input.txt | python -m task_reader.cli --stdin
```

### 首次启用本地 LLM

```bash
# 安装 Ollama（Windows）
winget install --id Ollama.Ollama
ollama pull qwen3:8b      # 约 5.2GB，之后全离线
```

未安装 Ollama / 未拉模型时，工具自动降级为纯规则模式并提示，不会报错。

## 输出 Schema

```json
{
  "task": "交论文",              // 任务名（动作+对象，或原文描述）
  "action": "交",                // 动作/动词
  "object": "论文",              // 动作对象（"把"字句也支持）
  "time_start": "2026-08-05 15:00",  // 起始时间（时间范围/截止时填充）
  "time_end": "2026-08-05 17:00",    // 结束时间（时间范围/截止时填充）
  "time": "2026-08-05 15:00",    // 归一化主时间，无法确定则为 null
  "time_text": "下周三",          // 原文时间短语
  "place": "图书馆",             // 地点（词典匹配）
  "notes": "",                   // 附加信息（结构化列表项内其它内容等）
  "raw": "下周三交论文",          // 对应子句原文
  "confidence": 0.935,           // 0~1 置信度
  "source": "rule"               // rule | llm | hybrid
}
```

## 支持的时间表达

| 类型 | 示例 | 归一化 |
|---|---|---|
| 绝对日期 | 2026年8月5日 / 8月5日 / 2026/8/5 | 2026-08-05 |
| 相对日 | 今天 / 明天 / 后天 / 前天 | ±N天 |
| 星期 | 下周三 / 本周五 / 周五 / 下周一 | 对应日期 |
| 周末 | 下周末 / 上周末 | 对应周六 |
| 周期 | 下周 / 下个月 / 今年 | 该周期起点 |
| 时段 | 月底 / 月初 / 本月底 | 对应日期 |
| X后 | 两周后 / 三个月内 / 年底前 | ref±N |
| 时刻 | 下午三点 / 晚上八点半 / 10:30 | 15:00 / 20:30 / 10:30 |
| 时间范围 | 下午3点到5点 / 2:00至4:00 / 晚上8点到10点 | time_start=15:00, time_end=17:00 |
| 截止 | 下周三之前 / 月底截止 | 标记 deadline |

## 鲁棒性 / 兼容性设计

- **多级回退**：LLM 失败 → 规则 → 正则，逐级降级不崩溃；无模型时纯规则可用。
- **置信度评分**：每个任务独立打分，低置信度字段保留原文。
- **分句容错**：一句话含多个任务（逗号/然后/顺便/还有…）自动拆成多条。
- **结构化列表**：自动识别 `1. 2. 3.`、`1、2、`、`1) 2)`；`3.14`/`1.5`/数量枚举
  （如"3个,5个"）不会误判。
- **头部时间上下文**：`今天任务：`/`周五计划：`等前缀被剥离，其中的时间作为整批任务的默认时间。
- **动词边界校验**：用 jieba 词边界避免"打印机"里的"打印"、"装修"里的"修"误判；
  单字动词（记/看/刷）必须正好是独立词，避免"记得"里的"记"、"看见"里的"看"误判。
- **"把"字句**：`把打印机修好` → 对象=打印机。
- **词典全部外置**：改 `task_reader/dicts/*.json` 即可扩展时间/地点/动词，无需改代码。
- **编码**：CLI 输出 UTF-8，兼容 Windows 控制台。

## 目录结构

```
task_reader/
  cli.py            # 命令行入口
  engine.py         # 主引擎：分句/抽取/融合/置信度
  normalize.py      # 预处理
  segment.py        # 分句
  time_parser.py    # 时间抽取与归一化（含中文数字）
  place_parser.py   # 地点词典匹配
  action_parser.py  # 动作/宾语抽取（动词词典+jieba+jieba边界校验）
  llm.py            # Ollama 本地模型客户端（JSON 容错）
  task_model.py     # 数据结构
  dicts/            # 外置词典（time/places/verbs/templates）
tests/              # 测试
```
